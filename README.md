# NewAssetsViewer

NewAssetsViewerは、Unityプロジェクト内で最近作成されたアセットを表示するエディタ拡張機能です。以下の機能を提供します。

### 画面
![image](https://github.com/user-attachments/assets/50ca0263-1aee-41d6-910e-96a4f5b7f1c5)
## 機能

- 指定した期間内にプロジェクトへ追加されたアセットを表示
  - 直近30分、直近24時間、今日、昨日から、先週から、直近N分（分数を指定）から選択可能
  - 追加日時は `.meta` ファイルの作成日時で判定するため、他の場所から移動してきたファイルも正しく拾えます
- `Packages/` 以下のアセットも含めるかどうかを切り替え可能（初期状態は `Assets/` のみ）
- アセットの並び順を選択
  - 追加日時順または名前順（数字を考慮した自然順）に並べ替え可能
  - 昇順または降順を選択可能
- 検索機能
  - アセット名で検索可能
  - 検索バーで ↓ キーを押すとリストへ移動
- アセットリストビュー
  - アセットアイコン・アセット名・フォルダパスを表示（同名ファイルも見分けられます）
  - クリックでプロジェクトウィンドウのアセットを選択・ハイライト（キーボード操作・複数選択にも対応）
  - ダブルクリックでアセットを開く
  - 右クリックメニューから「開く」「エクスプローラーで表示」「パスをコピー」
- 自動更新
  - アセットの追加・削除・移動を検知して、リストを自動で更新
- ドラッグ＆ドロップ機能
  - アセットをリストからドラッグして、他のウィンドウやフォルダにドロップ可能
- 表示範囲・並び順などの設定は、再コンパイルやウィンドウを開き直しても保持されます

## 使用方法

1. Unity エディタのメニューから "くろ～は/NewAssetsViewer" を選択して、ウィンドウを開きます。
2. 表示する期間を選択します。「直近N分（指定）」を選んだ場合は分数も入力します。
3. 必要に応じて並び順（追加日時または名前）と、昇順・降順を選択します。
4. パッケージ内のアセットも見たい場合は「Packages も含める」にチェックを入れます。
5. 検索バーを使用して、特定のアセットを検索できます。
6. リスト内のアセットをクリックすると、プロジェクトウィンドウでそのアセットが選択・ハイライトされます。
7. ドラッグ＆ドロップ機能を使用して、アセットを他のウィンドウやフォルダに移動できます。
8. 「直近30分」などの表示は時間の経過では自動更新されないため、必要に応じて "更新！" ボタンをクリックしてください。
